# Folio — 本を撮って、まとめる

本のページをスマホで撮影すると、AIが文字を読み取り、要約・重要ポイント・用語・発表原稿・レポート構成案まで整理するPWAです。

## 構成と技術選定の理由

| 部分 | 技術 | 理由 |
|---|---|---|
| アプリ本体 | PWA（HTML/CSS/JS、依存なし） | iPhone/Android両対応。ストア審査なしでホーム画面に追加できる |
| カメラ | `getUserMedia`（背面カメラ）＋ `<input capture>` のフォールバック | HTTPSでないとアプリ内カメラは使えないため、端末カメラ経由でも撮影できるようにした |
| 画像補正 | Canvas（端末内で処理） | 傾き補正、ページ端のトリミング、コントラスト調整、ぼやけ検出。画像を外部に出さずに行える |
| OCR・要約 | Claude API（画像入力対応） | 画像から直接文字を読み取れる。OCR後に別呼び出しで要約する |
| サーバー | Node.js（標準ライブラリのみ） | APIキーをサーバー側の環境変数に閉じ込め、フロントに出さないための中継役 |
| 保存 | IndexedDB | 要約と任意で撮影画像を端末内に保存。サーバーには保存しない |

## 起動方法

```bash
export ANTHROPIC_API_KEY=sk-ant-...      # 必須。コードやフロントには書かない
# 任意
export ANTHROPIC_MODEL=claude-sonnet-4-5 # 使うモデルを変更したい場合
export APP_PASSCODE=好きな合言葉           # 設定すると合言葉なしでは使えない（公開時の悪用防止）
node server.js                           # http://localhost:3000
```

Node.js 18 以上が必要です。`ANTHROPIC_API_KEY` が未設定の場合、アプリは「AIが設定されていません」と表示し、要約ボタンを無効にします。ダミーの結果は出しません。

## アプリとしてインストールする（PWA）

このアプリはPWAなので、HTTPSで公開したURLをスマホで開くと、アプリとしてインストールできます。

1. このフォルダをGitHubにアップロードし、Render（https://render.com）で「New → Blueprint」から選ぶ（`render.yaml` を同梱）
2. デプロイ時に `ANTHROPIC_API_KEY`（と任意で `APP_PASSCODE`）を入力
3. 発行されたURLをスマホで開く
   - **Android（Chrome）**: ホーム画面の「インストール」ボタン、またはメニューの「アプリをインストール」
   - **iPhone（Safari）**: 共有ボタン →「ホーム画面に追加」

ホーム画面から起動するとアドレスバーのない全画面で動き、見た目は通常のアプリと同じになります。

## スマホで使うには

アプリ内カメラ（`getUserMedia`）は **HTTPS** が必要です。次のいずれかで公開してください。

- Render / Railway / Fly.io などにこのフォルダをデプロイし、環境変数 `ANTHROPIC_API_KEY` を設定する（HTTPSは自動）
- 手元のPCで試すだけなら、Cloudflare Tunnel や ngrok でHTTPSのURLを発行する

公開したURLをスマホで開き、iPhoneは共有ボタンの「ホーム画面に追加」、AndroidはメニューのPWAインストールで追加できます。HTTPでも、端末のカメラアプリ経由の撮影とライブラリからの取り込みは使えます。

## 処理の流れ

1. 撮影時に端末内で補正（傾き・トリミング・コントラスト）し、ぼやけていれば警告
2. 確認画面で並べ替え・回転・削除
3. 3枚ずつ `/api/ocr` に送って文字認識。読めない箇所は `[判読不能]` と出力させる
4. 認識結果が約2.2万文字を超える場合は、約1.2万文字ごとに分割して部分メモを作り、最後に統合する。それ以下なら全ページを一度に要約する
5. 結果に出典（画像番号、読み取れた場合は本の印刷ページ番号）を付けて表示

## セキュリティ

- APIキーは `server.js` の環境変数のみ。フロントエンドには含まれません
- IPごとのレート制限（1分30回）、リクエストサイズ上限（25MB）あり
- 公開する場合は `APP_PASSCODE` の設定を推奨します（APIの利用料金を守るため）

## 既知の制限

- 補正は簡易的なアルゴリズムです。背景が白い机だとページ端の検出が効かず、トリミングされないことがあります
- 画像の傾きは±6度まで自動補正します。それ以上は回転ボタンと撮り直しで対応してください
- AIの出力にはAI自身の誤読・誤要約が含まれる可能性があります。結果画面の「読み取りテキスト」と出典の画像で、原文を確認してください
- ネイティブアプリではなくPWAのため、iOSでは一部の挙動（カメラ権限の再確認など）がブラウザ依存です

## ファイル

- `server.js` — 静的配信とAIプロキシ（`/api/status` `/api/ocr` `/api/summarize`）
- `index.html` — アプリ本体（全7画面）
- `sw.js`, `manifest.webmanifest`, `icon*` — PWA関連
